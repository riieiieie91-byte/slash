PTJ MINI BROWSER - BUILD APK TREN GITHUB

1) Giai nen ZIP.
2) Tao repository moi tren https://github.com (ten goi y: PTJ-Mini-Browser).
3) Upload TOAN BO noi dung thu muc PTJ_Mini_Browser_GitHub vao repository.
   Phai giu ca thu muc .github/workflows/build-apk.yml.
4) Mo tab Actions trong repository.
5) Chon workflow "Build PTJ Mini Browser APK".
6) Bam Run workflow (hoac doi workflow chay sau khi push len nhanh main).
7) Khi build xanh thanh cong, mo run vua hoan tat.
8) O muc Artifacts, bam PTJ-Mini-Browser-debug-APK de tai ZIP chua APK.
9) Giai nen ZIP artifact va cai app-debug.apk tren dien thoai.

Luu y:
- Khong upload file ZIP project nhu mot file don le; can upload cac file/thu muc ben trong ZIP vao repository.
- APK nay la ban debug de cai thu nghiem, chua phai ban phat hanh Play Store.
- Build can internet va GitHub Actions duoc bat cho repository.
- Neu build that bai, gui anh phan log do de sua.
